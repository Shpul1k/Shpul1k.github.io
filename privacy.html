Privacy Policy

Shorts Cutter · Last updated: November 7, 2026

Shorts Cutter is a desktop application that runs entirely on the user's own computer. It has no servers and does not send any data to the author.

What data is used

  • TikTok account: after the user signs in with TikTok Login Kit, the application receives an access token and basic profile information (open ID, display name, avatar) via the user.info.basic scope.
  • Videos: only the video files the user selects and chooses to publish.

How the data is used

  • The access token is used only to upload and publish videos that the user explicitly selects (video.upload and video.publish scopes) and to show which account is connected.
  • No data is sold, shared with third parties, or used for advertising or analytics.

Where the data is stored

Tokens, settings and video lists are stored only locally on the user's computer, in the application's data folder. Nothing is stored on any external server other than TikTok itself when a video is uploaded.

Deleting data

The user can disconnect the TikTok account in the application settings, which deletes the stored token, and can revoke access in the TikTok app (Settings and privacy → Security → Manage app permissions). Uninstalling the application and deleting its data folder removes all locally stored data.
